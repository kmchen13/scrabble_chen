# Politique de marque StarWords

La licence AGPL-3.0 régit le code source de StarWords. Cette politique régit l'utilisation du nom et du logo « StarWords ».

## Utilisations autorisées (sans autorisation préalable)
- **Référence descriptive** : « Basé sur StarWords », « Compatible avec StarWords », « Fork de StarWords ».
- **Redistribution de versions officielles non modifiées** : vous pouvez rediffuser le nom StarWords, à condition d'indiquer clairement qu'il s'agit d'une version officielle non modifiée.

## Utilisations nécessitant une autorisation écrite
- **Distribuer une version modifiée sous le nom StarWords** : si vous modifiez le code, vous devez utiliser un autre nom qui n'évoque pas starwords
- **Utiliser « StarWords » comme nom de produit, de service ou de domaine** : par exemple « StarWords Cloud », « StarWords Enterprise », ou intégrer StarWords dans un nom de domaine commercial.
- **Suggérer un soutien officiel ou une affiliation** : comme « officiel », « certifié », « partenaire ».
